# EDGE<span class="y">builder</span> docs

EDGEbuilder is a world builder for Cyberpunk 2077 that runs inside the game on REDnode: pick an asset from the game's own files, drop it into the live world, put it in place, arrange a scene, and bake it into a streaming sector that loads like any other mod. These pages hold the design and the results of each phase.

## Roadmap status

As of 2026-10-30 (design draft 4): B2b passed in game on 2.31, the 0.3.4 check on game 2.5 on 2026-10-29, and the bake probe on 2026-10-30 (baked sectors load on 2.5). B2c passed in game on 2026-10-30 (0.4.1). B3 Arrange and save is split in two: B3-1 Arrange passed in game on 2026-11-02 (0.5.8); B3-2 Save was planned on 2026-11-03 (design draft 5) and built the same day as 0.6.0; it passed in game and was released as 0.6.7 on 2026-11-05. Next: B4, B3c, B3b, B4b, B4c. The scene format is pinned and REDbridge can already bake one (not yet loaded in game). The first public release (a preview) follows B4 and 1.0 follows B4b and B5's lights: see [Release stages](design.md#release-stages).
